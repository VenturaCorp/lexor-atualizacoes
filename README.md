# LEXOR — diário de atualizações legislativas

Conteúdo servido ao aplicativo **LEXOR** para manter as leis em dia sem
depender de uma nova versão na loja.

## O que há aqui

- `manifesto.json` — versão e hash de cada uma das 331 leis do acervo;
- `leis/` — **apenas as leis alteradas** desde a última versão publicada do
  app. As demais já vão embutidas no aplicativo e não são hospedadas aqui.

## Procedência

O texto é o **oficial**, obtido do [Planalto](https://www.planalto.gov.br)
(páginas "Texto compilado") e, onde não há compilada, da
[Legislação Federal do Senado](https://legis.senado.leg.br). A estruturação em
dispositivos é feita automaticamente e cada lei passa por verificações de
integridade antes de ser publicada: nenhum artigo pode desaparecer, nenhum
dispositivo pode ficar órfão, e nada sai de revogado para vigente sem
justificativa. Lei que reprova fica retida, mantendo a versão anterior.

Atualizado automaticamente duas vezes por dia.

## Aviso

Este repositório contém **apenas texto de lei**, que é público por natureza.
O aplicativo LEXOR, seus mecanismos e seu código não estão aqui.

*LEXOR é marca registrada.*
